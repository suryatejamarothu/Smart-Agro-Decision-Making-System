# Smart Agro Decision Making System

## Description
This project is designed to assist in making agricultural decisions by analyzing various data inputs and providing crop recommendations based on trained machine learning models.

## Installation
To install the required dependencies, run:
```bash
pip install -r requirements.txt
```

## Usage
To run the application, execute:
```bash
python app.py
```

## Directory Structure
- `app.py`: Main application file.
- `train_model.py`: Script for training the machine learning model.
- `test_crop_recommendation.py`: Testing script for crop recommendations.
- `data/`: Directory containing data files.
- `dataset/`: Directory containing various datasets used in the project.
- `models/`: Directory containing trained models.
- `templates/`: Directory containing HTML templates for the web application.
- `requirements.txt`: Lists the required Python packages for the project.
